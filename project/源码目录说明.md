# 源码目录说明

本项目的源代码位于根目录（即 `../`），结构如下：

```
project/（本目录）
├── app/                    # 后端核心模块
│   ├── __init__.py
│   ├── llm.py              # 智谱GLM封装
│   ├── storage.py           # JSON存储 + 菜谱收藏/历史
│   ├── fridge.py            # 保质期计算 + 热量估算
│   ├── vision.py            # 拍照识别
│   ├── recipe.py            # 菜谱生成 + 每日三餐
│   ├── stats.py             # 浪费统计
│   └── main.py              # FastAPI路由（可选）
├── frontend/app.py          # Streamlit单体前端
├── tests/                   # 单元测试（105个用例）
├── data/                    # 数据文件
│   ├── shelf_life.json      # 保质期规则
│   └── fridge.json          # 食材数据
├── requirements.txt         # 依赖清单
├── .env.example             # 环境变量模板
├── start.bat                # 一键启动
├── demo.py                  # 演示脚本
└── streamlit_app.py         # Streamlit社区云入口
```

## 复现步骤

1. `pip install -r requirements.txt`
2. 配置 `.env`（参考 `.env.example`）
3. `python -m streamlit run frontend/app.py`
4. 浏览器打开 http://localhost:8501
