# 开源组件声明

本项目使用以下开源组件：

## 核心框架

| 组件 | 版本 | 许可证 | 用途 |
|------|------|--------|------|
| Streamlit | >=1.35 | Apache 2.0 | Web 前端框架 |
| FastAPI | >=0.110 | MIT | 后端 REST API（可选） |
| Uvicorn | >=0.29 | BSD-3-Clause | ASGI 服务器 |

## AI / 大模型

| 组件 | 版本 | 许可证 | 用途 |
|------|------|--------|------|
| OpenAI Python SDK | >=1.30 | Apache 2.0 | 智谱 GLM API 调用（OpenAI 兼容格式） |
| 智谱 GLM-4V | - | 商业 API | 图片识别 |
| 智谱 GLM-4-Flash | - | 商业 API | 文本生成 / 菜谱推荐 |

## 数据处理

| 组件 | 版本 | 许可证 | 用途 |
|------|------|--------|------|
| Pandas | >=2.0 | BSD-3-Clause | 数据处理 |
| Altair | >=5.0 | BSD-3-Clause | 数据可视化图表 |
| Pillow | >=10.0 | MIT-CR | 图片处理 |
| Pydantic | >=2.6 | MIT | 数据校验 |

## 工具库

| 组件 | 版本 | 许可证 | 用途 |
|------|------|--------|------|
| python-dotenv | >=1.0 | BSD-3-Clause | 环境变量管理 |
| requests | >=2.31 | Apache 2.0 | HTTP 请求 |

## 公网暴露

| 组件 | 许可证 | 用途 |
|------|--------|------|
| serveo.net | 免费服务 | SSH 隧道公网暴露 |
