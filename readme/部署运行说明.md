# AI 冰箱管家与剩菜改造师 - 部署运行说明

## 环境要求

- Python 3.10+
- pip 包管理器

## 一键安装与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置大模型 API Key

编辑 `.env` 文件，填入智谱 GLM API Key：

```
LLM_API_KEY=你的智谱API_Key
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
LLM_VISION_MODEL=glm-4v
LLM_TEXT_MODEL=glm-4-flash
```

智谱 API Key 申请地址：https://open.bigmodel.cn/

### 3. 启动应用

**Windows：** 双击 `start.bat`

**命令行：**
```bash
python -m streamlit run frontend/app.py --server.port 8501
```

### 4. 访问应用

浏览器打开 http://localhost:8501

### 5. 公网访问（可选）

双击 `start_public.bat`，通过 serveo.net SSH 隧道生成临时公网链接。
