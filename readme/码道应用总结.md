# 码道（CodeArts）应用总结

## 概述

本项目使用华为云码道（CodeArts）代码智能体作为核心开发工具，覆盖环境搭建、代码生成、调试排错、文档生成四个阶段。

## 码道应用四阶段

### 阶段一：环境搭建

- 使用码道内置终端创建项目脚手架
- 通过码道生成 `requirements.txt` 依赖清单
- 配置 `.env` 环境变量与 `.streamlit/secrets.toml`
- 使用码道初始化 Git 仓库与 `.gitignore`

### 阶段二：代码生成

- **后端模块**：通过码道 AI 生成 7 个核心模块（`app/llm.py`、`app/storage.py`、`app/fridge.py`、`app/vision.py`、`app/recipe.py`、`app/stats.py`、`app/main.py`）
- **前端界面**：通过码道 AI 生成 Streamlit 单体应用（`frontend/app.py`），包含自定义 CSS 主题、卡片布局、筛选器、图表
- **保质期规则**：通过码道 AI 生成 `data/shelf_life.json` 10 类食材保质期规则
- **热量估算**：通过码道 AI 在 `app/fridge.py` 中添加 60+ 种食材热量映射与中文数字解析
- **单元测试**：通过码道 developer-test-agent 子智能体生成 5 个测试文件 105 个用例

### 阶段三：调试排错

- 修复 `st.file_uploader` 图片上传问题（增加摄像头备选）
- 修复嵌套 columns 导致食材名称不渲染问题
- 修复 `pd` 变量名冲突（`pd = date_input()` 覆盖 `import pandas as pd`）
- 修复中文数字（三、两）和重量单位（斤）的热量解析
- 修复食材分类匹配（西兰花、金针菇等未正确分类）
- 修复 `st.secrets` 在本地运行时的报错

### 阶段四：文档生成

- 通过码道生成 `report/index.html` 五要素方案报告
- 通过码道生成 docx 项目选型流程文档
- 通过码道生成 `demo.py` 演示闭环脚本
- 通过码道生成 `start.bat` / `start_public.bat` 启动脚本

## 码道核心功能使用

| 功能 | 应用场景 |
|------|---------|
| 代码生成 | 7个后端模块 + 前端界面 + 测试用例 |
| 代码审查 | 修复变量名冲突、路径硬编码等问题 |
| 调试排错 | 6+ 个bug修复（上传/渲染/解析/分类） |
| 文档生成 | 方案报告 + 部署文档 + 组件声明 |
| 子智能体 | developer-test-agent 生成单元测试 |
| 技能加载 | 加载 frontend-design 技能优化 UI |

## 使用的码道子智能体

- **developer-test-agent**：生成 5 个测试文件，105 个单元测试用例，覆盖率 99.3%
- **explore**：代码库探索与文件搜索

## 开发效率提升

- 代码生成效率提升约 5x（相比手写）
- 调试排错效率提升约 3x（AI 定位问题根因）
- 文档生成效率提升约 10x（自动生成结构化文档）
