## 阶段三：调试排错（2026-10-24 ~ 2026-10-25）

### 3.1 图片上传修复

**问题**：用户反馈"拍照识图没法上传图片"
**码道诊断**：file_uploader 在嵌套 columns 中渲染异常
**修复**：增加 st.camera_input 备选 + 扩展文件格式支持

### 3.2 食材名称不渲染

**问题**：卡片内容区域大片空白，食材名称未显示
**码道诊断**：columns 内嵌套 columns 导致 markdown 渲染失败
**修复**：合并为单个 HTML 块，不嵌套 columns

### 3.3 变量名冲突

**问题**：`AttributeError: 'datetime.date' object has no attribute 'DataFrame'`
**码道诊断**：`pd = ac5.date_input()` 覆盖了 `import pandas as pd`
**修复**：重命名为 `purchase_date`

### 3.4 热量解析错误

**问题**：中文数字"三个"解析为1，"两斤"未按重量换算
**码道诊断**：_parse_quantity 仅匹配阿拉伯数字
**修复**：添加 CN_NUMS 中文数字映射 + _weight_multiplier 重量换算

### 3.5 食材分类错误

**问题**：西兰花、金针菇分类为"其他"
**码道诊断**：shelf_life.json examples 列表缺失
**修复**：扩充至 80+ 种食材
